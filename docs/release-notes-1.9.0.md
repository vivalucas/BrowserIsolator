# BrowserIsolator 1.9.0

## 新功能

- 新增独立采集模式：只开放绑定 `127.0.0.1` 的本机 CDP 端口，不修改页面 navigator 信息。
- 采集模式与差异模式可按环境独立组合；模式管理窗口支持搜索、仅显示可编辑环境和批量启用/关闭采集。
- 调试端口统一优先使用 `41000 + 环境编号`，冲突时自动尝试后续端口，并在高级详情中显示实际端口。

## 数据可靠性

- 配置保存时保留 `config.json.bak`。
- 主配置不可用时优先恢复备份；备份也不可用时扫描现有 `Profiles/pN` 重建环境列表。
- 最近使用时间进入配置持久化，重启后保持排序与详情展示。
- 配置读取会过滤非法编号和重复目录，磁盘重建只识别真实环境目录。

## 体验与兼容性

- 旧配置自动兼容：原差异模式设置保持不变，新增采集模式默认关闭。
- 配置恢复提示会明确区分备份恢复、磁盘重建和默认回退。
- 新增界面和恢复提示覆盖中文、英语、日语、韩语、德语、法语和俄语。
