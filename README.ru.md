# Изолятор браузера (BrowserIsolator)

Запускайте несколько изолированных сред Chrome на одном Mac. У каждой среды свои cookies, LocalStorage, пароли и состояние входа, поэтому с несколькими учетными записями можно работать без постоянного входа и выхода.

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md)

Цель BrowserIsolator проста: надежно разделять локальные браузерные среды. Это не полноценная антидетект-платформа и не обещание обхода систем контроля сайтов.

## Возможности

- **Изолированные среды**: каждая среда использует отдельный каталог данных Chrome
- **Быстрое управление**: запуск, закрытие и закрытие всех сред из панели или меню; при закрытии приложение ждет завершения Chrome
- **Информация о среде**: статус, папка, debug-порт для запущенного режима различий, размер на диске и время последнего использования
- **Имена и заметки**: переименование сред и короткие заметки для аккаунта, клиента или задачи
- **Совместимость по умолчанию**: обычно изолируется только профиль, без debug-порта и инъекции скриптов в страницы
- **Опциональное различие отпечатков**: включается отдельно для каждой среды в настройках; включенные среды при следующем запуске задают `navigator.hardwareConcurrency` и `navigator.deviceMemory`
- **Внешние ссылки**: можно сделать BrowserIsolator браузером по умолчанию и выбрать среду для ссылок из других приложений
- **Автоматическая установка браузера**: официальный Google Chrome скачивается при первом запуске
- **Обновления приложения**: проверка новых версий через Sparkle и GitHub Releases
- **Локальное хранение**: настройки и профили остаются на Mac
- **7 языков**: 中文, English, 日本語, 한국어, Deutsch, Français, Русский

## Требования

- macOS 13 Ventura или новее
- Apple Silicon Mac (M1 или новее)

Текущая сборка предназначена для `arm64-apple-macosx13.0` и не поддерживает Intel Mac.

## Установка

### Вариант 1: DMG

1. Скачайте последнюю `BrowserIsolator.dmg` на странице [Releases](../../releases)
2. Откройте DMG и перенесите `BrowserIsolator.app` в Applications
3. Если macOS сообщает, что разработчик не проверен или приложение повреждено:

   ```bash
   xattr -cr /Applications/BrowserIsolator.app
   ```

Дальнейшие обновления можно проверить в **Настройки -> О программе и поддержка -> Проверить обновления**. Первая установка по-прежнему выполняется через DMG со страницы Releases.

### Вариант 2: сборка из исходников

Только исполняемый файл:

```bash
cd BrowserIsolator
swift build -c release -Xswiftc -target -Xswiftc arm64-apple-macosx13.0
```

Сборка `.app`:

```bash
./build.sh
```

## Браузерный движок

BrowserIsolator использует отдельную копию официального Google Chrome. Ваш обычный Chrome не читается и не изменяется.

Расположение:

```text
~/Library/Application Support/BrowserIsolator/Chromium/Google Chrome.app/
```

Если автоматическая загрузка не удалась, скачайте Google Chrome вручную и поместите `Google Chrome.app` в `~/Library/Application Support/BrowserIsolator/Chromium/`.

## Использование

- **Запуск**: нажмите Запустить в строке среды; при сбое появится ошибка
- **Закрытие**: нажмите Закрыть у работающей среды; статус Закрытие отображается до завершения Chrome
- **Закрыть все**: кнопка в панели инструментов
- **Добавить**: кнопка Добавить среду
- **Переименовать / заметки / удалить**: через правый клик или правую панель сведений. При удалении данные перемещаются в корзину
- **Внешние ссылки**: в **Настройки -> Внешние ссылки** выберите целевую среду и сделайте BrowserIsolator браузером по умолчанию
- **Настройки**: статус Chrome, папки данных, внешний вид, язык, обновления, контакт и обратная связь
- **Различия окружений**: включаются для каждой среды в настройках. Работающую среду изменить нельзя; закройте ее и запустите снова
- **Язык**: меню с глобусом в панели инструментов или меню

## Расположение данных

```text
~/Library/Application Support/BrowserIsolator/
├── config.json          # среды, имена и заметки
├── Chromium/
└── Profiles/
```

Для полного удаления удалите папку `BrowserIsolator`.

## FAQ

### Почему не использовать установленный Chrome?

Чтобы не затрагивать ваш основной браузер. BrowserIsolator использует собственную копию Chrome и отдельные профили.

### Поможет ли это избежать блокировки аккаунтов?

Гарантий нет. Проект делает прежде всего локальную изоляцию и при необходимости легкое различие отпечатков, но не обещает обход обнаружения.

### Что меняется в отпечатке?

По умолчанию ничего не инъектируется. BrowserIsolator отдает приоритет режиму совместимости и изолирует только локальные данные профиля.

Если в настройках включить различия окружений, при следующем запуске через Chrome DevTools Protocol задаются `navigator.hardwareConcurrency` и `navigator.deviceMemory` для каждой среды. BrowserIsolator регулярно синхронизирует текущие page targets, поэтому новые вкладки тоже получают инъекцию. Это не полная симуляция устройства.

Этот режим влияет на параметры запуска Chrome и использование CDP, поэтому его нельзя менять для работающей среды.

### Chrome обновляется автоматически?

Нет. Для обновления удалите `~/Library/Application Support/BrowserIsolator/Chromium/` и запустите приложение снова.

### BrowserIsolator обновляется автоматически?

Приложение может проверять обновления. Используйте пункт Проверить обновления в меню или **Настройки -> О программе и поддержка**. BrowserIsolator проверяет новые версии через Sparkle и GitHub Releases.

### Как открывать ссылки из других приложений в выбранной среде?

Откройте **Настройки -> Внешние ссылки**, выберите среду и нажмите «Сделать браузером по умолчанию». После этого http/https-ссылки из почты, чатов, заметок и других приложений будут отправляться в выбранную среду. Если браузерная среда ещё не готова, BrowserIsolator покажет предупреждение и предложит скопировать ссылку.
