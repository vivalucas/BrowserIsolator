# Изолятор браузера (BrowserIsolator)

Запускайте несколько изолированных сред Chrome на одном Mac. У каждой среды свои cookies, LocalStorage, пароли и состояние входа, поэтому с несколькими учетными записями можно работать без постоянного входа и выхода.

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md)

Цель BrowserIsolator проста: надежно разделять локальные браузерные среды. Это не полноценная антидетект-платформа и не обещание обхода систем контроля сайтов.

## Возможности

- **Изолированные среды**: каждая среда использует отдельный каталог данных Chrome
- **Быстрое управление**: запуск, закрытие и закрытие всех сред из панели или меню; среду можно запустить двойным щелчком по строке, а при закрытии приложение ждет завершения Chrome
- **Информация о среде**: список слева показывает статус, размер на диске и время последнего использования; правая панель показывает путь профиля, режим запуска, ошибки, действия и расширенные детали. Debug-порт показывается только при необходимости в расширенных деталях
- **Имена и заметки**: переименование сред и короткие заметки для аккаунта, клиента или задачи
- **Безопасное удаление**: при удалении нужно ввести имя среды, после чего данные перемещаются в корзину
- **Базовый режим по умолчанию**: обычно изолируется только профиль, без debug-порта и инъекции скриптов в страницы
- **Опциональный режим различий**: включается отдельно для каждой среды в настройках; включенные среды при следующем запуске задают `navigator.hardwareConcurrency` и `navigator.deviceMemory`
- **Внешние ссылки**: можно сделать BrowserIsolator браузером по умолчанию и выбрать среду для ссылок из других приложений; если цель недоступна, приложение покажет предупреждение вместо потери ссылки
- **Автоматическая установка браузера**: официальный Google Chrome скачивается при первом запуске
- **Настройки**: статус и версия Chrome, папки данных, копирование путей, повторная загрузка Chrome, внешние ссылки, язык, внешний вид, расширенные детали, обновления, контакты и обратная связь
- **Восстановление конфигурации**: если `config.json` поврежден или не читается, BrowserIsolator загружает значения по умолчанию и по возможности сохраняет поврежденный файл
- **Локальное хранение**: настройки, Chrome и профили остаются на Mac; BrowserIsolator не загружает и не собирает пользовательские данные
- **7 языков**: 中文, English, 日本語, 한국어, Deutsch, Français, Русский

## Требования

- macOS 13 Ventura или новее
- Apple Silicon Mac (M1 или новее)

Текущая сборка предназначена для `arm64-apple-macosx13.0` и не поддерживает Intel Mac.

## Установка

### Вариант 1: DMG

1. Скачайте последнюю `BrowserIsolator.dmg` на странице [Releases](../../releases)
2. Откройте DMG и перенесите `BrowserIsolator.app` в Applications
3. Если macOS сообщает, что разработчик не проверен или приложение повреждено:

   ```bash
   xattr -cr /Applications/BrowserIsolator.app
   ```

Дальнейшие обновления можно проверить в **Настройки -> О программе и поддержка -> Проверить обновления**. Первая установка по-прежнему выполняется через DMG со страницы Releases.

### Вариант 2: сборка из исходников

Только исполняемый файл:

```bash
cd BrowserIsolator
swift build -c release -Xswiftc -target -Xswiftc arm64-apple-macosx13.0
```

Сборка `.app`:

```bash
./build.sh
```

## Браузерный движок

BrowserIsolator использует отдельную копию официального Google Chrome. Ваш обычный Chrome не читается и не изменяется.

Расположение:

```text
~/Library/Application Support/BrowserIsolator/Chromium/Google Chrome.app/
```

Если автоматическая загрузка не удалась, скачайте Google Chrome вручную и поместите `Google Chrome.app` в `~/Library/Application Support/BrowserIsolator/Chromium/`.

## Использование

- **Запуск**: нажмите Запустить в строке среды, дважды щелкните строку или используйте правую панель сведений; при сбое появится ошибка
- **Закрытие**: нажмите Закрыть у работающей среды; статус Закрытие отображается до завершения Chrome
- **Закрыть все**: кнопка в панели инструментов
- **Добавить**: кнопка Добавить среду
- **Переименовать / заметки / удалить**: через правый клик или правую панель сведений. При удалении данные перемещаются в корзину
- **Внешние ссылки**: в **Настройки -> Внешние ссылки** выберите целевую среду и сделайте BrowserIsolator браузером по умолчанию. Если среда еще не готова или доступной среды нет, ссылку можно скопировать; когда доступной среды нет, можно также открыть главную панель
- **Настройки**: статус Chrome, папки данных, копирование путей, повторная загрузка Chrome, внешний вид, язык, обновления, контакт и обратная связь. Повторная загрузка Chrome доступна только когда ни одна среда не запускается, не работает и не закрывается
- **Режим различий**: включается для каждой среды в настройках. Работающую среду изменить нельзя; закройте ее и запустите снова
- **Язык**: меню с глобусом в панели инструментов или меню

## Расположение данных

```text
~/Library/Application Support/BrowserIsolator/
├── config.json          # среды, имена и заметки
├── Chromium/
│   └── Google Chrome.app/
└── Profiles/
    ├── p1/
    ├── p2/
    └── p3/
```

Для полного удаления удалите папку `BrowserIsolator`.

Если `config.json` поврежден или не может быть прочитан, BrowserIsolator покажет предупреждение, загрузит конфигурацию по умолчанию и попытается сохранить исходный файл как `config.corrupt-<timestamp>.json`.

## FAQ

### Почему не использовать установленный Chrome?

Чтобы не затрагивать ваш основной браузер. BrowserIsolator использует собственную копию Chrome и отдельные профили.

### Поможет ли это избежать блокировки аккаунтов?

Гарантий нет. Проект делает прежде всего локальную изоляцию и при необходимости легкий режим различий, но не обещает обход обнаружения.

### Что делает режим различий?

По умолчанию ничего не инъектируется. BrowserIsolator отдает приоритет базовому режиму и изолирует только локальные данные профиля.

Если в настройках включить различия окружений, при следующем запуске через Chrome DevTools Protocol задаются `navigator.hardwareConcurrency` и `navigator.deviceMemory` для каждой среды. BrowserIsolator регулярно синхронизирует текущие page targets, поэтому новые вкладки тоже получают инъекцию. Это не полная симуляция устройства.

Этот режим влияет на параметры запуска Chrome и использование CDP, поэтому его нельзя менять для работающей среды.

### Chrome обновляется автоматически?

Нет. Для обновления сначала используйте **Настройки -> Повторно загрузить Chrome**. Все среды должны быть остановлены и не должны запускаться или закрываться. Также можно удалить `~/Library/Application Support/BrowserIsolator/Chromium/` и запустить приложение снова.

### BrowserIsolator обновляется автоматически?

Приложение может проверять обновления. Используйте пункт Проверить обновления в меню или **Настройки -> О программе и поддержка**. BrowserIsolator проверяет новые версии через Sparkle и GitHub Releases.

### Как открывать ссылки из других приложений в выбранной среде?

Откройте **Настройки -> Внешние ссылки**, выберите среду и нажмите «Сделать браузером по умолчанию». После этого http/https-ссылки из почты, чатов, заметок и других приложений будут отправляться в выбранную среду. Если браузерная среда ещё не готова или доступной среды нет, BrowserIsolator покажет предупреждение и предложит скопировать ссылку. Когда доступной среды нет, можно также открыть главную панель.
