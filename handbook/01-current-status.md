## 活跃任务

2.0.0（build 47）为当前源码交接版本，整合三语言与统一组件规范：普通/主要操作 32 点高、快捷操作 28 点、设置操作列 156 点；默认浏览器入口与其余设置操作使用同档中性样式。主窗口、设置、模式管理、输入与错误恢复路径复用公共组件。本次按授权推送 main 与 v2.0.0 标签，通过 GitHub Actions 发布安装包；不替换本机已安装程序；既有功能与数据兼容约定不变。

## 当前能力快照

- 独立 Chrome 环境的创建、启动、关闭、重命名、备注、删除和磁盘信息展示已实现。
- 基础、采集、差异和采集+差异四种模式已实现；新建环境（含首次生成）默认开启采集、关闭差异。已有环境保留原设置，旧配置缺少采集字段及磁盘重建仍默认关闭。
- 配置支持主文件、`.bak` 和磁盘扫描三级恢复，损坏主文件会另存诊断副本。
- 外部 http/https 链接可进入指定环境；Sparkle 负责应用内更新。
- CI 在 `main` push、PR 和手动触发时运行 Swift 测试与 arm64 Release 构建；发布 workflow 在 `v*` 标签上运行测试、构建 DMG、生成 appcast 并创建 Release。
